# Yeeun's Portfolio

개인 포트폴리오 웹사이트입니다. 디지털 서비스, AI·데이터 프로젝트와 학습 기록을 한곳에서 확인할 수 있도록 정리했습니다.

## Portfolio

- **Website:** https://yeeun-portfolio-gamma.vercel.app/
- **Repository:** https://github.com/yeeun-lee-bit/yeeun-portfolio

## Site sections

- **Projects:** 앱, AI·데이터, 웹 프로젝트와 관련 저장소
- **Journal:** 학습 과정과 개발 기록
- **About:** 관심 분야와 소개
- **Contact:** 프로젝트 및 협업 문의 경로

## Implementation

이 저장소는 별도 빌드 도구 없이 브라우저에서 실행되는 정적 웹사이트입니다.

- HTML: 페이지 구조와 콘텐츠
- CSS: 반응형 레이아웃과 시각 디자인
- JavaScript: 메뉴와 프로젝트 필터 등 상호작용
- Web App Manifest / Service Worker: 설치형 웹앱 및 캐시 기능의 기반

## About

웹 개발과 AI·데이터 기반 디지털 서비스에 관심을 가지고 프로젝트를 진행하고 있습니다. 사용자에게 필요한 문제를 발견하고, 웹 기술과 AI 도구를 활용해 해결 방법을 구현하는 데 집중합니다.

## Explore

사이트에서 프로젝트별 주요 기능과 사용 기술을 확인할 수 있습니다. 각 프로젝트 카드의 저장소 링크를 통해 관련 코드를 살펴볼 수 있습니다.
