# Yeeun Portfolio — Private Development

개인 개발 포트폴리오와 엔지니어링 기록을 위한 반응형 웹앱(PWA)입니다.

> **개발 원칙:** 완성 및 사용자 확인 전에는 공개 배포하지 않습니다.

## 현재 구성

- 반응형 개인 포트폴리오 랜딩 페이지
- 프로젝트 카드와 카테고리 필터
- 모바일 메뉴 및 키보드 접근성 기본 지원
- PWA manifest와 기본 오프라인 캐시
- 프로젝트 소개와 기술 정보는 검증 후 업데이트

## 파일 구조

```
.
├── index.html
├── styles.css
├── script.js
├── manifest.webmanifest
├── sw.js
└── assets/
    └── favicon.svg
```

## 로컬 미리보기

Python이 설치되어 있다면 저장소 루트에서 실행합니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 서비스 워커와 PWA 설치 동작을 확인하려면 localhost 또는 HTTPS 환경을 사용하세요.

## 배포 정책

- 저장소는 Private으로 유지합니다.
- 완성 전 GitHub Pages 및 기타 공개 배포를 활성화하지 않습니다.
- 공개 전 프로젝트 설명, 링크, 기술 스택, 개인정보를 검토합니다.
- 공개 전환은 소유자의 확인 후에만 진행합니다.

## 검토할 사항

- 프로젝트 설명이 실제 구현 범위와 일치하는지 확인
- 실제 프로젝트 저장소 및 데모 링크 연결
- 샘플 저널을 실제 글로 교체하거나 미게시 상태로 유지
- 모바일, 키보드 접근성, 브라우저 콘솔 및 오프라인 동작 테스트
- 외부 폰트 의존성 및 아이콘 표시 확인
